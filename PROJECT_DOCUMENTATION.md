## 🔙 الباك اند (Backend)

### التقنيات المستخدمة
- **Flask** - إطار عمل Python للويب
- **Gunicorn** - خادم WSGI للإنتاج
- **SQLAlchemy** - ORM للتعامل مع قواعد البيانات
- **Flask-Login** - إدارة جلسات المستخدمين
- **Celery** - معالجة المهام الخلفية

### ملفات الباك اند الرئيسية

| الملف | الوظيفة | الشرح التفصيلي |
|-------|---------|----------------|
| `app.py` | التطبيق الرئيسي | إعداد Flask، تسجيل الـ Blueprints، إعداد قاعدة البيانات، Health Checks |
| `celery_app.py` | إعداد Celery | تكوين معالج المهام الخلفية مع RabbitMQ و Redis |
